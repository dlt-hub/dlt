# Security and compliance

Security and compliance documents for the dltHub platform, including our SOC 2 reports, are available in the [dltHub Trust Center](https://app.eu.vanta.com/dlthub.com/trust/3kalag7qbkrdnr55t1fg2z). For other security questions, email [support@dlthub.com](mailto:support@dlthub.com).

## SOC 2

The dltHub platform has SOC 2 Type 1 and SOC 2 Type 2 reports, both issued by an independent auditor with a clean opinion. The audits cover ScaleVector GmbH, the company that operates the platform.

You can request both reports through the [dltHub Trust Center](https://app.eu.vanta.com/dlthub.com/trust/3kalag7qbkrdnr55t1fg2z).

## Data residency

Each organization is assigned to a data region, currently US or Europe, which determines where your code, configuration, secrets, and workload data are stored. See [Regions and data residency](../platform-capabilities/regions.md).
